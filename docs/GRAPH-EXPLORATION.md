# Exploring your knowledge graph

The graph is a 2D reading surface over retained source tags, assigned topics, and relationships you save. It shares canonical topics with Library, writing, and topic homes. It never changes the 3D world's coordinates, pins, physics, or links.

The constellation presentation follows the project's dedicated visual reference: charcoal canvas, ivory source nodes, warm topic nodes, restrained teal and coral relationship colors, and an inspector that follows the workspace theme. Circular images appear only where an existing source already has a retained local raster thumbnail. At most 24 thumbnails load, each bounded to 1 MiB; no external image or tracking URL loads.

Select a node to bring its actual neighborhood into focus. Hovering previews the same neighborhood without changing selection. Search filters by source or topic name; press Enter to explore the first match with its neighbors. The source inspector offers the original, an expanded excerpt, highlight count, and an editable writing copy. Topic nodes open their shared topic home. Source originals and citation provenance remain authoritative.

Drag the canvas to pan. Scroll or use the zoom buttons, and use Fit to frame the visible graph. Drag a node to pin its position **in this open 2D graph view**. P toggles a focused node's pin; Alt + arrow keys move and pin it, with Shift for a larger step. Release pin or Release all graph pins returns nodes to layout. Pins remain in component memory while the workspace stays open and reset on workspace replacement; they are not 3D pins or portable saved layout data.

Only saved manual directed relationships receive an arrow and a finite trace. Supports is teal; contradicts is coral and dashed; builds-on is slate blue. Related remains undirected. Source-tag membership is dotted and assigned-topic membership is teal. The trace describes saved link direction, not factual certainty. Layout distance establishes no evidence support.

Motion uses a bounded deterministic layout and finite, interruptible SVG presentation transitions. Existing positions warm-start expansions, new nodes enter from real visible neighbors when available, and the graph settles after each action. There is no ambient force simulation or continuous rendering loop. Motion paused finishes the current transition and disables subsequent transitions/traces. A live `prefers-reduced-motion` preference always disables motion. Activity cleanup, workspace replacement, or unmount cancels scheduled animation frames. The sidebar's decorative artwork is separate from these graph semantics.

Global pages retain 80 nodes. Local neighborhoods expand in steps of 80 to 320, with at most 400 rendered links. Counts disclose connections continuing beyond the canvas. The searchable node list and connection list provide keyboard access and routes into omitted neighborhoods. Label budgets keep large views legible while full names remain available through accessible node names and the list.

The layout and motion helpers are [graphMotion.ts](../src/reading/graphMotion.ts), with the [interactive graph](../src/reading/KnowledgeGraph.tsx) and [styles](../src/reading/graph.css).
