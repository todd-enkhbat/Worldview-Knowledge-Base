## Coverage and interpretation

The search started with the department’s faculty directory, which returned 33 named full-time, affiliated and emeritus faculty, including Barnard appointments. Each name was searched for public syllabi or reading recommendations. Department and personal teaching pages, signed interviews and public Columbia Core material supplied the positive records. The directory is a starting population. Material inside CourseWorks, unpublished teaching and unindexed pages limit what a public review can establish. The table records the outcome of this search for each listed person. [Department directory](https://philosophy.columbia.edu/content/faculty)

An assignment is specific to its course, section and term. A program list is attributed to the program. A publisher-only assignment supplies no translator vote. A personal favorite reported by an interviewer carries that attribution in the app. For course editions with documented copies, the search leads with the copy supported by the greatest number of distinct named sources in this index, counting a co-taught syllabus once. Overlap between the Core curriculum and an individual section demonstrates repeated use and does not measure independent scholarly agreement.
